# Title
CRM Application – Playwright Automation Testing Framework

# Description
This project automates end-to-end workflows of a Customer Relationship Management (CRM) application using Playwright with JavaScript. It uses the Page Object Model (POM), reusable fixtures, and data-driven testing to create a maintainable and scalable automation framework.

# Aim
To automate CRM application workflows, reduce manual testing effort, improve test coverage, and ensure application functionality through reliable and repeatable automated tests.

# Explanation
The framework automates key CRM modules, including Leads, Organizations, Contacts, Opportunities, Products, Quotes, Sales Orders, and Invoices. It supports cross-browser testing using Chrome, Firefox, and WebKit, manages test data using JSON files, and generates HTML test reports. Jenkins is used to integrate automated test execution into a CI/CD pipeline.
**Technologies Used:** JavaScript, Playwright Test, Node.js, JSON, Git, GitHub, and Jenkins.
**Key Concepts:** Page Object Model (POM), Data-Driven Testing (DDT), reusable fixtures, cross-browser testing, and CI/CD integration.

# Conclusion
This project demonstrates practical skills in test automation, framework development, and continuous integration. It helps improve testing efficiency, maintainability, and regression test execution for CRM business workflows.
